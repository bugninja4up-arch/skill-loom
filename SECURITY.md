# Security

Skill Loom is a local tool, not a hardened multi-user or internet-facing service. Keep it on localhost, allow only narrow skill directories, and keep the full session URL private. Use independent backups for important data.

Do not place API keys, tokens, personal data, or private skill content in public issues. A successful plan validation does not establish that AI-generated instructions are correct or safe.

Use the repository's **Security → Report a vulnerability** option if private vulnerability reporting is enabled. If that option is absent, do not post exploit details or secrets publicly: open a minimal issue asking the maintainer to enable a private reporting channel, without disclosing the vulnerability.

There is no published security response-time commitment. This project has not undergone an independent security audit. Supported behavior and privacy limits are described in README.md.
